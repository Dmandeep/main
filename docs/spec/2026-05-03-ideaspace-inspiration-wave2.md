## Patterns worth translating into IdeaSpace
1) Section rhythm that does not feel random
   - Hero -> how it works -> feature grid -> proof/social -> FAQ -> final CTA.
   - Use this cadence for landing but swap in proof-first modules.

2) Evidence blocks beat claims
   - Miter/Meter/DeepJudge lead with metrics, logos, and real customer stories.
   - IdeaSpace should show real student activity, verified builds, and outcomes.

3) Comparison frames build trust
   - Merlin uses a strong comparison table vs traditional assistants.
   - Add IdeaSpace vs "WhatsApp groups / random forms" comparison.

4) Visual system cards and dashboards
   - Clario/Meter show clear product cards and dashboards as proof of clarity.
   - Use compact idea cards, proof cards, and workshop cards with live status.

5) Step-by-step clarity
   - Clario/Miter make onboarding feel inevitable with steps and visuals.
   - Use a 3-step "Proof Pipeline": Post -> Build -> Verify.

6) System narrative
   - Lovart sells "thinking in systems" and consistency across assets.
   - Position IdeaSpace as a system for ideas, not a feed of posts.

7) Technical credibility without heaviness
   - Composio uses clean code blocks and numbered pillars.
   - Show a lightweight "rules of proof" block and point logic preview.

## Design actions for IdeaSpace
- Add "Proof Pipeline" section on landing with 3 steps and status chips.
- Create an "Evidence Wall" section that shows verified builds and timestamps.
- Add a comparison table: IdeaSpace vs WhatsApp/Forms/Discord.
- Introduce "Outcome stats" (projects shipped, hours saved, workshops run).
- Add a "Campus partners" strip (clubs, labs, departments).
- Use a compact KPI strip on feed and leaderboard pages.
